# Plataforma para Freelancers

## Objetivo

Desenvolver uma rede profissional integrada que proporcione um ambiente seguro, saudável e colaborativo, oferecendo mais visibilidade para freelancers iniciantes. A plataforma busca facilitar a conexão entre profissionais autônomos e oportunidades de trabalho, promovendo crescimento, networking e desenvolvimento profissional.

## Funcionalidades

- Cadastro e perfil personalizado para freelancers
- Publicação e busca de vagas/projetos
- Sistema de avaliações e recomendações
- Mensagens diretas entre usuários
- Painel de oportunidades em destaque para iniciantes
- Ambiente seguro com moderação de conteúdos e perfis

## Tecnologias Utilizadas

- **JavaScript**
- **HTML5**
- **CSS3**
- **TypeScript**
